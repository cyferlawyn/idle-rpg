# idle-rpg

A near-zero-player browser RPG. Your toon adventures on its own — leveling
skills, fighting monsters, working quests — and the player's job is to nudge
it in a direction rather than control it directly.

Being built in the open with a devlog series on [cyferlawyn.org](https://cyferlawyn.org).

See [DESIGN.md](./DESIGN.md) for the design doc (core loop, the "nudge" control
model, planned systems, and open questions).

## Dev

```
npm install
npm run dev      # local dev server
npm test         # vitest, headless sim tests
npm run build    # typecheck + production build
```
